# WhalePhone Agent

机主正常用手机的同时,agent 在**同一台设备**上把任务办完,全程不碰他的屏幕、焦点、
键盘和剪贴板。配置一次之后不需要电脑,agent 自己在手机上跑。

**思路:给 agent 单独造一块屏。** Android 的输入、焦点、输入法每一层都假设「一人一屏」。
与其在这些全局单例上排队,不如让两边看不见彼此 —— 用 shell 身份造一块**受信虚拟显示器**,
agent 的一切都发生在那上面;用无障碍服务跨屏读写,它是唯一带显示器维度的通道。

```
┌──────────────── 手机(自足运行,不需要电脑)────────────────┐
│  Display 0 机主在用  ◄─ 从不触碰 ─  Display N agent 副屏     │
│        ▲                                ▲  flags 0x5e08     │
│        │ 只读:机主在用什么 / 键盘弹着没  │ 读 + 写           │
│  ┌─────┴────────────────────────────────┴──────────────┐    │
│  │ EyesAndHands(无障碍服务)                             │    │
│  │ getWindowsOnAllDisplays 跨屏读 · performAction 写     │    │
│  └─────┬─────────────────────────────┬──────────────────┘    │
│  ┌─────┴──────────────┐ ┌────────────┴──────────────────┐    │
│  │ AgentService 前台服务│ │ ShellBridge(shell UID)        │    │
│  │ 感知→模型→动作 循环 │ │ 由 Shizuku 拉起                │    │
│  │ 每步写进 AgentBus    │ │ 造受信副屏 / 带屏号的按键与启动 │    │
│  └─────┬──────────────┘ └───────────────────────────────┘    │
│  ┌─────┴──────────────────────────────────────────────────┐  │
│  │ 机主这一侧(全部可关,默认只有通知)                        │  │
│  │ MainActivity 对话流 · 通知 · 悬浮球(可语音) · 副屏取景窗 │  │
│  └────────────────────────────────────────────────────────┘  │
└────────┼──────────────────────────────────────────────────────┘
         └─ HTTPS ─► 任意 OpenAI 兼容的 LLM(默认 DeepSeek)
```

触摸、焦点、输入法、剪贴板、导航键**全机只有一份**,所以这道题的实质是资源隔离,
不是自动化。量到十类冲突,处理掉八类(音频和悬浮窗可见性如实留着)。最难的是焦点:
副屏上出现可获焦窗口时主屏会丢掉自己的焦点窗口 —— 机主键盘被收起、他的 App 报
「应用未响应」,是同一件事的两个后果。解法是 `OWN_FOCUS` + `STEAL_TOP_FOCUS_DISABLED`
+ 副屏跨任务复用 + 机主打字时事前避让。一条绕不过的边界:副屏和主屏共用电源组,
agent 的可工作时间等于机主的亮屏时间。

## 跑起来

手机上完成,不需要电脑:

1. 装 [Shizuku](https://shizuku.rikka.app/),按它的引导用**无线调试**启动。它的服务
   只能由 shell 拉起,所以**每次重启都要重开一次**(电脑在手边也可以
   `bash scripts/start-shizuku.sh`)
2. 装本项目 APK,打开后点「授权 Shizuku」
3. 右上角齿轮里填模型接口(只有 `LLM_API_KEY` 必填,默认打 DeepSeek),回到主界面
   说一句要它做什么

无障碍权限不用手动开:开跑前自己打开、收工后自己关掉 —— 常开的无障碍服务会让微信
收银台拒绝付款。只动自己那一项,机主原有的读屏服务不受影响。主界面底部有两个可选
悬浮窗(默认关):「看副屏」把那块看不见的屏按 5 帧/秒搬到主屏一角,上面的「接管」
能把 agent 手上这件事整个搬到眼前;「悬浮球」不打开 app 也能下任务(点一下就地展开语音 —— 但实测这台三星上四个语音引擎
全要连 Google 的服务器而它连不上,所以语音在这台机器上不可用,见 FINDINGS)。
两个都带 `FLAG_NOT_FOCUSABLE`,不碰焦点也不碰输入法。

它默认记着上一件事(对话落盘),点「新任务」才清;要花钱、要给人发消息这类不自己
拍板,会停下来问。从源码构建 `./gradlew assembleDebug`;Windows 上项目路径含非 ASCII
字符时 AGP 会拒绝构建,用 `mklink /J C:\wp <路径>` 对着联接构建。
